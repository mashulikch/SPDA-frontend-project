# Система оптимальной парковки

Адаптивный фронтенд для подбора свободного парковочного места по типу автомобиля и условиям поездки. Проект работает на React, TypeScript и Vite.

## Запуск

Нужны Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:8443`). Для проверки сборки:

```bash
pnpm typecheck
pnpm build
```
Если не запускается, можно попробовать:
```bash
npm install
npm run dev
```

## Что есть в интерфейсе

- схема парковки с занятыми и свободными местами;
- выбор типа автомобиля, потребности в зарядке и доступном месте;
- подбор подходящего места, альтернативы и маршрут от въезда;
- состояние отсутствия подходящих мест;
- адаптивная версия для телефона.

## Данные

Сейчас занятость задана в `src/parking.ts` константой `BUSY`. Это демонстрационные данные. Для реальной парковки понадобится источник текущей занятости (API или датчики), а также подтверждённые размеры мест и план проездов. Подбор в текущем проекте работает на клиенте по этим примерным данным.

Схема парковки находится в `src/ParkingMap.tsx`, панели выбора и результата — в `src/Panels.tsx`, состояние экрана — в `src/App.tsx`.
